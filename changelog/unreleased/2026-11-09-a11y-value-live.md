- **`El::a11y_value_live(&LiveText)` gives an element's accessible value from a live text.** Assistive technology hears its latest text without the view running again, as `live_text` paints it: the tree update after a `LiveText::set` resends the element with the new value, on a frame with no commit. It replaces `a11y_value` on the same element. Made for values that change on frames where nothing else does, such as a playhead's spoken position.
